# Wild

A pair of kid-friendly learning games — **WordWild** (sight words) and **NumberWild** (numbers and math) — plus a home page that links to both.

No app store, no build tools, no accounts. Progress stays on the device.

## Play on an iPad (GitHub Pages)

1. In the GitHub repo, open **Settings → Pages**.
2. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to `main`, folder to `/` (root), then Save.
3. After a minute, the site is at `https://<your-github-username>.github.io/childrens-learning-apps/`.
4. Open that URL in Safari on the iPad.
5. Tap Share → **Add to Home Screen** so it runs full-screen like an app.

Pin the hub (recommended) so your kid can pick a game. You can also pin a game page directly.

Progress saves in that browser on that iPad. Nothing is uploaded. The same URL on another device starts fresh.

## Play a file locally

Open `index.html` in a browser, or open `word-wild/wordwild.html` / `number-wild/numberwild.html` directly.
